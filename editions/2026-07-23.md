# Edição de 2026-07-23 / Weekly Edition — 2026-07-23

## 🇧🇷 Português

### 🚀 Technical News / Novidades Técnicas

#### LWC (Lightning Web Components)
- **Disponibilidade Geral (GA) do Salesforce Multi-Framework para React**: O suporte nativo para aplicações React no Salesforce atingiu GA. A solução elimina a necessidade de gerenciamento manual de tokens e autenticação OAuth, oferecendo integração nativa com governança da plataforma, operações de dados via GraphQL e chamadas diretas a métodos Apex. — 📅 16/07/2026 · 🔗 [Leia mais](https://developer.salesforce.com/blogs/2026/07/build-with-react-on-salesforce-multi-framework-is-now-ga)

#### Data Cloud
- **Desafios Arquiteturais de Deduplicação e Governança no Data Cloud**: A adoção do Data Cloud (Data 360) exige forte governança de dados e regras de *survivorship* nos sistemas de origem. A consolidação de perfis e a resolução de identidade da plataforma não substituem o saneamento prévio de registros duplicados de Contas, Contatos e Leads. — 📅 22/07/2026 · 🔗 [Leia mais](https://www.salesforceben.com/deduplication-and-data-cloud-you-have-an-architecture-problem/)

#### Flow
- **Execução de Flows via Hosted MCP Servers no Slack**: Com a introdução do Headless 360 e dos servidores MCP hospedados pela Salesforce, interfaces conversacionais no Slack agora podem invocar Flows de forma segura, realizar consultas no CRM e expor relatórios do Tableau sem expor dados sensíveis. — 📅 15/07/2026 · 🔗 [Leia mais](https://developer.salesforce.com/blogs/2026/07/connect-slack-to-salesforce-with-hosted-mcp-servers)
- **Gerenciamento de Contexto de Precisão com MCP+**: A nova camada de pós-processamento MCP+ intercepta respostas de ferramentas MCP para entregar apenas o contexto estritamente necessário aos agentes de IA, otimizando custos e consumo de tokens em execuções automatizadas sem alterar o código do Flow ou da ferramenta subjacente. — 📅 21/07/2026 · 🔗 [Leia mais](https://developer.salesforce.com/blogs/2026/07/get-started-with-precision-context-management-using-mcp)

### 💡 Impacto Prático
A chegada do Salesforce Multi-Framework para React em GA permite que equipes de desenvolvimento modernizem a experiência do usuário reutilizando ecossistemas React sem violar os padrões de segurança do Salesforce. Paralelamente, arquitetos que implementam o Data Cloud devem priorizar o saneamento de dados na origem, pois a resolução de identidade não resolve falhas estruturais de duplicidade. Por fim, a expansão de servidores MCP hospedados e do ecossistema MCP+ exige testes rigorosos em sandboxes para validar permissões de segurança antes de permitir que agentes de IA executem Flows ou acessem dados de produção.

## 🇺🇸 English

### 🚀 Technical News / Novidades Técnicas

#### LWC (Lightning Web Components)
- **General Availability of Salesforce Multi-Framework for React**: Native support for building React applications on Salesforce is now GA. This framework eliminates custom OAuth and session token management while providing out-of-the-box governance, GraphQL data fetching, and direct Apex method invocation. — 📅 16/07/2026 · 🔗 [Read more](https://developer.salesforce.com/blogs/2026/07/build-with-react-on-salesforce-multi-framework-is-now-ga)

#### Data Cloud
- **Architectural Implications of Deduplication in Data Cloud**: Enterprise implementations highlight that Data Cloud (Data 360) identity resolution cannot replace foundational data governance and record stewardship. Resolving duplicates requires strict upstream survivorship policies rather than relying purely on platform unification rules. — 📅 22/07/2026 · 🔗 [Read more](https://www.salesforceben.com/deduplication-and-data-cloud-you-have-an-architecture-problem/)

#### Flow
- **Slack-Driven Flow Execution via Hosted MCP Servers**: Using Headless 360 and Salesforce Hosted MCP Servers, conversational interfaces like Slackbots can now securely trigger Salesforce Flows, query CRM records, and retrieve Tableau analytics directly within workspace channels. — 📅 15/07/2026 · 🔗 [Read more](https://developer.salesforce.com/blogs/2026/07/connect-slack-to-salesforce-with-hosted-mcp-servers)
- **Precision Context Management with MCP+**: A new post-processing layer, MCP+, intercepts MCP tool responses to filter and deliver only the required context to AI agents, optimizing operational cost and token usage without modifying underlying tools or Flow orchestrations. — 📅 21/07/2026 · 🔗 [Read more](https://developer.salesforce.com/blogs/2026/07/get-started-with-precision-context-management-using-mcp)

### 💡 Practical Impact
The GA release of Salesforce Multi-Framework for React enables engineering teams to build custom web UIs using React natively without introducing security gaps or manual token management overhead. However, architects working on Data Cloud initiatives must enforce strict data quality controls upstream, as platform identity resolution does not cure underlying duplicate data issues. Furthermore, the adoption of Hosted MCP Servers and MCP+ requires immediate sandbox validation to ensure proper access controls before exposing internal Flow automations and CRM objects to external AI agents.
